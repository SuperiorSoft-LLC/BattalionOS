# calls-app (fixture)

A page-only app (AND-4) with one button per native call of a page: pick a file, pick a folder, open a link, a notice, scan a QR
code, and a spawn call (always refused on a phone). Each answer is written on the page. Package the same page with an empty
`permissions` list to see each call refused with its permission's name. Throwaway keys only, made at test time.
